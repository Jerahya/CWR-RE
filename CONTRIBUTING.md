# Contributing

Thank you for your interest in CWR-RE, a community fork of the Poseidon engine
source code released by Bohemia Interactive (<https://github.com/BohemiaInteractive/CWR>).
CWR-RE is not affiliated with Bohemia Interactive. Please report problems with this
fork here, not to Bohemia Interactive.

## Issues

- Include the CWR-RE commit or version, operating system, reproduction steps,
  expected behavior, actual behavior, and logs.
- Do not report security vulnerabilities in public issues.

## Pull Requests

- Keep changes focused and describe what they change and why.
- Do not add game data or assets (models, textures, sounds, missions, voices),
  compiled binaries, or keys to the repository.
- Do not use "ARMA", "Operation Flashpoint", or other Bohemia Interactive or
  Electronic Arts trademarks or logos as names, branding, or artwork. Mentioning
  them to describe where the code came from or which file formats it reads is fine.
